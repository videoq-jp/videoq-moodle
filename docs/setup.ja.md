# LTI 1.3 で LMS と連携する

VideoQ は LTI 1.3 の質問画面と Moodle 用の教材同期プラグインを提供しています。
学校が所有する既存の VideoQ アカウントに教材を同期し、所有者の保存容量・
処理枠・回答枠を使います。先生・生徒ごとの VideoQ アカウントは不要です。

設定値・マイグレーション・同期プラグインの導入・受け入れ確認の詳細は、
[英語版の完全な導入ガイド](setup.md) を参照してください。

## 接続コードでかんたん設定

Moodle管理者と学校のVideoQアカウントの所有者が、初回だけ設定します。

1. Moodleに `local_videoq` と `ltisource_videoq` の2つのプラグインをインストールし、
   管理画面のプラグイン更新を完了します。
2. VideoQの **設定 → Moodleと連携** で、MoodleのURL（例：`https://moodle.example.jp`）を
   入力し、**接続コードを発行** を押します。サブディレクトリがある場合は含めてください。
3. **Moodleの接続画面を開く** から管理者としてログインし、コードを貼り付けて **接続** を押します。

LTI 1.3外部ツールの作成、VideoQアカウントとの紐付け、同期キーの設定、接続確認を
自動で行います。クライアントIDやJSONを手入力する必要はありません。
コードは指定したMoodleに限定され、10分間・1回の接続に有効です。
再発行すると以前の未使用コードは無効になります。
通信エラーの後は同じコードで再試行してください。登録済みの接続は上書きしません。
未完了の設定は、まだVideoQに登録されていなければ接続画面から中止できます。

接続後、先生は **動画をファイル教材として追加 → 教材の「VideoQの質問機能」を有効化**
するだけです。受講者はMoodleのログインで講座共通のAIアシスタントを利用します。

サーバー管理者は、あらかじめ最新のVideoQマイグレーションを適用し、APIの `LTI_CONFIG` に
`toolOrigin` と `databaseRegistrations: true` を設定してください。
MoodleのcronとVideoQのワーカー・キュー・ストレージ・復旧／削除の定期処理も必要です。
学校の所有者アカウントの保存容量・処理枠・回答枠が適用されます。

配布ZIPはリポジトリから次のコマンドで作成できます。

```bash
node scripts/package-plugins.mjs /private/videoq-moodle-plugins
```

`local_videoq.zip` と `ltisource_videoq.zip` をMoodleのプラグインインストール画面から
順に導入します。手動で配置する場合は、それぞれ `local/videoq` と `mod/lti/source/videoq` に
置きます（Moodle 5.1のソース構成では `public/` 配下）。

従来の管理コマンドによる接続設定も利用できます。詳細は完全版ガイドを参照してください。

## 手動の LTI 接続

LTI の授業・リソースと VideoQ コースを管理者が明示的に紐付ける構成も利用できます。
Moodle 5.1.8+ のローカル環境で検証されており、LTI 認証取得済みではありません。
Canvas・manaba・WebClass などは、それぞれの環境で検証が必要です。

現時点では Deep Linking、名簿連携、成績返却などは含みません。
Google Classroomとの接続はVideoQ本体側の別の連携機能です。


## 講座共通のAIアシスタント

「一般」に講座全体へ質問する入口を1つ置き、各章にはMoodle標準の動画教材を
配置します。同期を有効にすると共通の入口が作られます。入口は特定の動画に
依存せず、その受講者が閲覧できる処理済み教材で開きます。対象教材がない場合は
案内を表示します。旧教材へのブックマークも、移行後の連携先で開けます。

Moodleのステルス活動を有効にしている場合、連携用LTIと動画ごとの質問用リンクは
コース一覧に重複表示しません。動画の公開状態・利用制限は質問のたびに再確認します。

試用環境では、3本を横断する実AI回答、30分動画の末尾を根拠とする回答、100人分の
実セッションからの同時質問が成功しました。同時質問の95パーセンタイルは約6.7秒でした。
これは試用環境の測定であり、本番回線での連続動画再生や任意のサーバ構成の性能を
保証するものではありません。本番のMoodle cron・監視通知・バックアップ保持は
運用環境に合わせて設定してください。


動画ごとのリンクも講座共通のAIアシスタントを開き、その動画が選択された状態になります。
受講者・講座ごとに直近50往復を最終回答から24時間引き継ぐため、別の動画から開き直したり、
別タブで開いたりしても会話を続けられます。非公開化などで閲覧できる動画の範囲が減った場合は、
以前の会話を引き継ぎません。Good／Badは現在のセッション用に再発行した参照で更新します。


## Moodleで動画を削除した場合

Moodleの元の動画教材を削除すると、次の定期同期でVideoQの動画・文字起こし・検索データ・
保存ファイルも削除します。ライブラリはページへ戻ったときと表示中の30秒ごとに一覧と件数を
取り直し、Moodle側の変更を反映します。連携用LTIや内部リンクだけの削除は、元動画の削除と
区別し、動画を残して連携用項目を修復します。

## 教材を残して接続を解除する

VideoQの **設定 → Moodleと連携** で、対象サイトの **接続を解除** を押し、
説明を確認して **解除する** を選びます。接続を所有するアカウントだけが操作できます。

解除後の同期とMoodleからのLTI起動・質問・履歴取得・評価の更新を停止します。
そのアカウント・サイト向けの未使用の接続コードも無効になります。
すでに受け付けた処理は完了する場合があります。他の接続は継続します。

Moodleの教材、VideoQの講座・同期済み動画・文字起こし・検索データ・保存済み質問ログは
削除しません。通常の保存期限は引き続き適用されます。設定画面には「接続解除済み」と
表示します。Moodle側の接続設定は保持されるため、接続確認ではエラーになる場合があります。
この操作では設定のリセットや別アカウントへの付け替えは行いません。
