# 先生向け：授業でVideoQを使う

学校管理者による[導入・通信許可](setup.ja.md)の後、先生が自分のVideoQアカウントと講座を接続します。動画の登録・編集はVideoQで行います。

## 初回の接続

1. 編集権限のある先生としてMoodleの担当講座を開き、「自分のVideoQアカウントを接続」を選びます。
2. VideoQで、表示されたMoodle講座名と接続先の自分のアカウントを確認します。別のアカウントなら接続せず、正しいアカウントでログインし直します。
3. 自分が所有するVideoQ講座を選び、「このアカウントで接続」を押します。
4. 接続完了の表示が出たらMoodleの授業画面に戻り、更新してVideoQを開きます。

Moodleの1講座には、責任者となる先生1人のVideoQアカウントと講座を紐付けます。共同教師は他の先生の接続を上書きできません。教材・AIなどには接続した先生の利用枠を使います。生徒のVideoQ登録は不要です。

## 授業前の確認

- 意図した講座名と動画一覧が表示され、動画が再生できる。
- 生徒として開いたとき、教材が表示され、自分の質問履歴だけが復元される。
- 生徒に先生用の「講座の質問履歴」が表示されない。

AIへの質問送信は利用枠を消費します。接続だけの確認では新しい質問を送る必要はありません。

## 質問を確認・CSVに出力する

接続した講座所有者の先生が、MoodleのVideoQ画面で「AIアシスタント → 講座の質問履歴」を開きます。画面は最新100件、CSVボタンは対象の履歴全件を出力します。質問・回答、質問者の名前・メールアドレス、引用、評価などを確認できます。CSVは閲覧権限のある人だけで管理してください。

この履歴は接続先VideoQ講座の履歴です。その講座を本体や別の授業でも使っている場合、その利用分も含みます。授業ごとに分析対象を分けたい場合は、接続するVideoQ講座も分けてください。

講座の所有者でも、現在のMoodleの教材管理権限が必要です。生徒や別の共同教師には所有者の履歴・CSVを公開しません。

## 受講・接続を止める

- 生徒1人の利用を止める場合：Moodleの参加者管理で受講を停止・解除します。以後の教材・履歴取得で現在の権限を確認します。
- 授業との接続を止める場合：VideoQの「設定 → 外部連携」で、対象の「Moodle · 講座ID」を確認して連携を解除します。同名の講座が複数ある場合はIDも確認してください。
- 再開する場合：同じ責任者が初回と同じ接続手順を行います。別の先生や別のVideoQ講座への変更は既存接続を上書きできないため、運用担当者に相談してください。

連携解除は教材・質問履歴の削除ではありません。取得済みのCSVや再生用URLを回収する操作でもありません。個人データの削除は[プライバシー対応](privacy.md)に従います。

## 表示されないとき

接続先アカウント・講座、学校の通信許可、現在の受講状態・Moodle権限、VideoQ動画の処理完了を確認して更新します。解決しなければ、発生時刻・Moodle講座ID・操作名を管理者に伝えてください。パスワードやAPIキーは送らないでください。
