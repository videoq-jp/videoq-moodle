# 生徒向け：MoodleでVideoQを使う

Moodleのアカウントで利用します。VideoQへの新規登録やAPIキーの設定は不要です。

1. Moodleにログインし、受講している講座の「VideoQ」を開きます。
2. 「動画一覧」から教材を選んで再生します。
3. 「AIアシスタント」に教材について質問します。講座内の複数の動画を対象に質問できます。Enterで送信、Shift＋Enterで改行します。
4. 回答の引用時刻を押すと、その教材の該当箇所に移動できます。回答は動画と照らし合わせて確認してください。

以前の自分の質問・回答は画面を開き直すと復元され、会話は自動で続きます。現在のMoodle画面には、別の「新しい会話」「質問履歴一覧」を選ぶ操作はありません。他の生徒の会話や先生用の講座質問履歴・CSVは利用できません。

人に聞きたい内容は講座の「質問・回答」を使います。講座Q&Aは授業内の共有投稿で、個人のAI会話とは別です。

動画や履歴を開けない場合は、受講中の正しい講座か確認して画面を更新し、先生に連絡してください。受講停止・受講解除や授業のVideoQ連携解除後は、利用できなくなります。
